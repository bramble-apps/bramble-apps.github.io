# Bramble Office website

The landing page for Bramble Office (Keydeck, Values and Letters), served by GitHub Pages.

- `index.html` — the page
- `obtainium.html` — where the "Get it on Obtainium" badges land: builds the `obtainium://app` import link for one app (`?app=letters`) or all four (`?app=all`), with no third-party redirect. The badge (`img/badge-obtainium.png`) is from the Obtainium project (GPL-3.0), trimmed
- `features.html` — feature voting; reads open issues labelled `feature-request` from this repo and sorts them by 👍
- `.github/ISSUE_TEMPLATE/feature_request.yml` — the form the "Request a feature" button opens
- `img/`, `vid/` — app screenshots and the scroll-driven demo videos (recorded in the apps)
- `logo/` — the berry mark and the logo sheet
- `fonts/` — the "No font? No problem." strip's fonts (the apps' built-in stand-ins for Apple fonts, cut down to the letters on the cards by ~/CascadeProjects/matched-fonts), each with its licence

Photos in the sample documents are free photos from Unsplash.
